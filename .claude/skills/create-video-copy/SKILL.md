# create-video-copy

손그림 느낌의 커플 공감 세로 루프 영상(MP4 + GIF)을 만든다.

기준작 (사용자 승인 퀄리티, 새 작업은 항상 이 수준 이상이어야 한다):
- `episodes/fart_history.py`: "우리 사이 방@귀 변천사". 위아래 2컷 리빌형으로, 사용자가 말한 **"인스타 느낌"의 기본형**이다.
- `episodes/dating_1y_vs_3y.py`: 2x2 4컷형. 사용자가 "완전 좋다"고 한 작품이다.
- `episodes/dating_1y_vs_3y_slide.py`: 1x1 슬라이드형.

## 진행 원칙

- 사용자와 **회의하듯** 진행한다. 3단계를 나눠서, **단계마다 검수(OK)를 받은 뒤에만** 다음 단계로 넘어간다.
- 대화는 한국어로 한다. 결정이 필요한 것은 선택지 2~4개와 추천안으로 묻는다.
- `$ARGUMENTS`로 주제나 레퍼런스가 주어지면 1단계에서 그것부터 다룬다.
- 레퍼런스 영상이 첨부되면 **구조만 보지 말고 스토리, 문구, 말투까지** 분석한다.
  - ffmpeg로 컨택트 시트와 확대 프레임을 만들어 글자를 정확히 읽는다.
  - 원문(제목, 라벨, 말풍선)을 표로 옮긴 뒤 공식을 뽑는다.
  - 화면 밝기 변화로 컷이 등장하는 타이밍을 잰다.

## 1단계: 주제

- **생활 밀착형 몸 개그와 커플 공감** 소재를 3~4개 제안한다. 예: 방귀, 똥, 뱃살, 식욕, 잠, 싸운 뒤, 편해진 모습.
- 각 후보마다 제목 안, 기대 컷, 반전 컷을 한 줄씩 붙인다.
- 비교 축 예시: 연애초 vs 현재, 1년차 vs 3년차, 여친 vs 남친.
- 사용자가 고르거나 수정하면 2단계로 간다.

## 2단계: 스토리 + 자막 (기획 공식)

1. **"우리" 시점의 커플 일기**로 쓴다. 예: "우리 사이…", "우리의…", "내 눈에…".
2. **제목은 반어, 결론은 애정**으로 쓴다.
   - 예: "행복해졌다는 증거"라면서 똥과 벌크업을 보여준다.
   - 반전 컷에도 반드시 애정 장치를 둔다. 예: "귀엽눙", 하트 후광, 응원, 주고받기.
   - **권태나 무관심으로 읽히면 실패**다. 예: 폰만 보며 "ㅇㅇ" 하는 남친.
3. **반전은 극단에서 극단으로** 간다. 왕자 → 똥만 쌈, 숨김 → 응원함, 참음 → 대화함.
4. **시끄러움과 고요함의 대비**도 펀치라인이 된다. 한쪽은 대사·효과음 폭발, 다른 쪽은 대사 없이 그림만 둔다.
5. 글은 최소로 하고, 웃음은 그림(표정, 포즈, 배경 분위기)이 만든다.

### 말투 규칙

| 규칙 | 예시 |
|---|---|
| 받침 ㅇ 붙이기 (애교체) | 다녀왕, 마니묵넹, 귀엽눙, 외톨이얌, 웅, 왜 그랭? |
| 혀짧은 소리 | 곤듀(공주), 왕쟈(왕자), 쟈닌해(잔인해), 뷰끄롱(부끄러워) |
| @ 끼워넣기 | 강조나 말장난: 치@명적, 증@거, 변@화, 방@귀 / 욕 가리기: 샤@갈 |
| 4+4 별명 라벨 | "여친:" 아래 두 줄로 쌓는다. 예: 큐티요정 / 뽀짝곤듀, 방구참기 / 3시간째 |
| 명사형 종결 | 숨김, 응원함, 똥만 쌈, 푸파됨, 방귀를 참음 |
| 유행어·줄임말 | 느좋, 푸파, 벌크업, 뽀짝, 선빵 |
| 말풍선 1~4글자 | 앙!, 웅, 뿡?, 뿡!, 다녀왕, (꾸욱..) |
| 효과음 늘이기 | 끼이이잉!, !!!!! |

- 평범한 표준어 설명문은 피한다. 예: "풀메하고 설레며 등장", "어때?", "국물 줘".

## 3단계: 제작

1. 준비: `bash .claude/skills/create-video-copy/scripts/setup.sh` (ffmpeg, Pillow, 나눔 폰트)
2. 에피소드 파일 작성: `episodes/<slug>.py`. 같은 레이아웃의 기준작을 복사해 시작한다.
3. 시안 확인: `python3 .claude/skills/create-video-copy/scripts/build.py episodes/<slug>.py <scratchpad>/<slug> --only <프레임>`
   - 결과 PNG를 직접 Read로 보고 겹침, 잘림, 어색한 포즈를 고친다.
   - 직접 1~2회 다듬은 뒤 사용자에게 보여준다.
   - 리빌형은 아래 컷이 나온 뒤의 프레임(예: 50)으로 확인한다.
4. 전체 빌드: `python3 .claude/skills/create-video-copy/scripts/build.py episodes/<slug>.py <scratchpad>/<slug>`
   - `<slug>.mp4`, `<slug>.gif`, `preview.html`이 만들어진다.
   - 리빌 전, 페이드 중, 리빌 후 프레임을 이어 붙여 움직임과 등장이 실제로 바뀌는지 확인한다.
5. 전달: 먼저 SendUserFile로 mp4와 gif를 보낸다. 실패하면 `preview.html`을 Artifact로 게시한다. 같은 영상의 수정본은 같은 file_path로 재게시해 링크를 유지한다.
6. 검수 요청: 그림체와 표정, 문구와 말투, 움직임과 타이밍. 수정을 반영해 같은 링크로 재게시한다.
7. 승인되면 에피소드 파일을 커밋한다. 산출물(`out/`, mp4, gif)은 커밋하지 않는다. 사용자가 원하면 예외로 한다.
8. 아웃트로(인스타 로고와 계정명)는 넣지 않는다. 사용자가 요청할 때만 넣는다.

## 레이아웃 3종

### ① 위아래 2컷 리빌형 (기본, "인스타 느낌")
- 흐름: 노란 제목 상자(한 줄) 아래에 가로형 컷 2개가 있다.
  - 위 컷이 3초 단독으로 나온다.
  - 아래 컷이 0.5초 페이드인된다.
  - 두 컷을 같이 유지한다. **위 컷은 사라지지 않는다.**
  - 9.5초 루프이고, 루프 직전에 아래 컷이 살짝 페이드아웃된다.
- 에피소드 설정:
  - `LAYOUT = "reveal"`
  - `TITLE = "한 줄"`
  - `REVEAL_AT = 30`
  - `N = 95`
  - `PANELS = [(컷함수, "연애초: ○○함", 배경), (컷함수, "현재: ○○함", 배경)]`
- 컷은 848x487 로컬 좌표다. **굵고 거친 검정 테두리**와 노란 태그는 엔진이 자동으로 그린다.
- 배경은 **분위기가 꽉 찬 배경**이다. 위아래 분위기가 대비되게 한다.
  - `bg_gradient(w,h,c1,c2,c3)`: 파스텔 반짝이
  - `bg_heart_glow`: 핑크 하트 후광
  - 단색 튜플
  - 필요하면 어두운 방, 집중선 같은 배경을 엔진에 추가한다.
- 구석 라벨은 `side_label(p, x, y, ["여친:", "…"])`로 단다. 캐릭터는 머리 반지름 85~95로, 좌우에 한 명씩 둔다.

### ② 2x2 그리드
- 4컷을 한 화면에 동시에 보여준다. `CELLS`에 4개(좌상, 우상, 좌하, 우하)를 넣는다. 컷은 470x450이다.
- **흰 바탕에 캐릭터만** 둔다. 컷 테두리와 배경색은 쓰지 않는다.
- 비교형은 위 줄 = A, 아래 줄 = B, 같은 열 = 같은 소재로 둔다.

### ③ 1x1 슬라이드
- 한 컷씩 2배 크기로 보여주고, 페이드로 사라지면 다음 컷이 나온다.
- 에피소드 설정:
  - `LAYOUT = "slide"`
  - `SLIDES = [(컷함수, 태그, 캡션), ...]`
  - `FRAMES_PER_SLIDE = 25`
  - `N = FRAMES_PER_SLIDE * len(SLIDES)`
- 캡션은 **컷 위**에 둔다. 진행 점(●○○○)은 **표시하지 않는다**(사용자 요청). `DOTS = True`일 때만 나온다.
- 같은 컷 함수를 재사용할 수 있다. 예: `episodes/dating_1y_vs_3y_slide.py`.

## 그림 스타일 규칙 (공통)

- **표정과 포즈가 웃음 포인트**다. 반짝눈, 눈물, 하트눈, 질끈 눈(> <), 반쯤 감은 눈, 눈곱, 하품, 침, 콧방울, 땀, 떨림 표시, 볼터치 빗금, 시뻘개진 얼굴(`face_fill`)을 쓴다.
- **펜 선**: 굵기가 들쭉날쭉한 도장 브러시(`Pen.stroke`)를 쓴다. 매 프레임 boil(t % 3)로 미세하게 떨린다.
- **움직임**: 컷마다 포즈 2개 이상을 교체한다(덜덜, 갸웃, 땀방울 위치, 하트·Zzz 상승, 구름 크기). 리빌형은 아래 컷 안에서도 시간차 연출을 넣는다(예: "뿡?" 뒤 1초 후 "뿡!").
- **색**: 진한 대비를 쓴다. 핫핑크 리본, 갈색 곰, 노란 반짝이, 빨강 입.
- **글씨**: 얇은 나눔바른고딕(일반 굵기)을 쓴다. 제목 52~54, 태그 34, 라벨과 말풍선 28~32.
- 한 컷 = 캐릭터 1~2명 + 소품 0~1개다.

하지 말 것 (실제로 "별로"라는 피드백을 받은 원인):
- 색 배경 박스 8칸을 빽빽하게 배치한 인포그래픽 느낌
- 작은 캐릭터 + 식탁, 폰, 소파, 간판 같은 소품 과다
- 팔다리 없는 눈사람 캐릭터, 모든 컷이 정면에 같은 자세
- 굵기가 일정한 매끈한 벡터 선, 흐린 파스텔 캐릭터, 두꺼운 둥근 고딕
- 설명문 캡션과 표준어 대사, 무관심 결말

## 에피소드 파일 예시 (리빌형)

```python
import math
from cartoon import *

LAYOUT = "reveal"
TITLE = "우리 사이 방@귀 변천사"
VERSION = "시안 v1"
FPS = 10
REVEAL_AT = 30
N = 95

def cut_early(p, t):            # 로컬 좌표 (0..848, 0..487), t = 전체 프레임 번호
    sh = 3 if t % 2 else -3     # 덜덜
    bunny(p, 300 + sh, 245, 90, 0, "squeeze", "wobbly", ("blush+",),
          body=(300 + sh, 388, 68, 58), face_fill=(255, 150, 160))
    p.bubble(150, 125, "(꾸욱..)", 28, (225, 180))
    side_label(p, 85, 382, ["여친:", "방구참기", "3시간째"], 28)

PANELS = [(cut_early, "연애초: 방귀를 참음", lambda w, h: bg_gradient(w, h, (205,242,236), (255,246,214), (255,214,232))),
          (cut_now, "현재: 방귀로 대화함", bg_heart_glow)]
```

## 엔진 API 요약 (`engine/cartoon.py`)

- 캐릭터
  - `bunny(p, hx, hy, hr, tilt, eyes, mouth, extras, body=(x,y,rx,ry), arms=[((어깨),(손))], arms_back=..., ribbon=True, ears="up"|"messy", body_fill=BUNNY|HOODIE, face_fill=BUNNY)`: 여친 토끼
  - `bear(p, hx, hy, hr, tilt, eyes, mouth, extras, body=..., arms=..., face_fill=BEAR)`: 남친 곰
- 표정 값
  - `eyes`: `sparkle` `teary` `heart` `dot` `down` `happy` `closed` `half` `squeeze`
  - `mouth`: `kiss` `smile` `grin` `flat` `wobbly` `yawn` `o` `drool`
  - `extras`: `blush` `blush+`(빗금) `boogers` `sweat`
- 펜(`p`)
  - 도형: `blob(cx,cy,rx,ry,fill,w,ang)`, `capsule(p0,p1,r0,r1,fill)`(팔다리), `shape(pts,fill,w)`, `line(pts,w)`, `arc(...)`
  - 장식: `heart`, `sparkle`, `bubble(x,y,글,크기,꼬리끝)`, `text(x,y,글,크기,색,anchor)`
- 소품과 효과: `popcorn(p,x,y,s,tipped)`, `puff(p,x,y,s)`(방귀 구름), `tag(p,x,y,글)`, `side_label(p,x,y,[줄들])`
- 배경 (리빌형): `bg_gradient(w,h,c1,c2,c3)`, `bg_heart_glow(w,h)`. 캐시되므로 매 프레임 호출해도 된다.
- 그리는 순서가 곧 앞뒤 관계다. 뒤에 있는 것을 먼저 그린다. 껴안는 팔처럼 앞으로 나와야 하는 부위는 `capsule`로 마지막에 덧그린다.
- 새 캐릭터, 표정, 소품, 배경이 필요하면 `engine/cartoon.py`에 **추가**한다.
  - 기존 함수의 기본 동작은 바꾸지 않는다.
  - 엔진을 고친 뒤 기준작 프레임 하나를 렌더링해 이전과 픽셀이 같은지 확인한다.
